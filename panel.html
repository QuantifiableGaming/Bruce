Coach voice

Get more voices
  1. Click Open Windows voice settings.
  2. Under Manage voices, click Add voices, choose a voice (for example English (Australia)), and click Add.
  3. Wait for the download to finish, then click Refresh voice list here.

Some newer Windows voices, such as the "Natural" voices, do not work with the coach. If a new voice does not show in the list after a refresh, the coach cannot use it.

ElevenLabs voices (optional)

Use ElevenLabs voices
ElevenLabs voices sound more human than Windows voices. You need an ElevenLabs account and an API key. Each spoken line uses ElevenLabs characters. The coach keeps a copy of each line, so a repeated line is free. If ElevenLabs does not answer, the Windows voice speaks.

Troubleshooting

Record the next match
Use this only when the coach misses rounds or reads wrong numbers. For the next time you click Start coach, the coach saves every reading it takes, with pictures of the screen, to the recordings folder. One Swiftplay match uses about 100 to 200 MB. The switch turns off again after that match. Delete old recordings when you do not need them.

Match reports

The coach saves one report per match: the result, the stats for each round, and what it said.

Progress

Your last matches, newest first. In the four coach columns, lower is better. An empty cell means too little data. Combat score and K/D/A come from the scoreboard: open the SUMMARY tab after a match while the coach runs. The list above the reports filters both lists by game type. Matches from before 19 Nov have no game type, so they show only under "All matches". The debrief compares only matches in the current season.
